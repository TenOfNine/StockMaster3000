# Erkenntnisregister

Jede Trading-Session liest diese Datei. Neue Erkenntnisse werden unten
angehängt; bestehende Einträge werden nur im Feld Status fortgeschrieben.

Format:

    ## L-001 Kurztitel
    - Datum: JJJJ-MM-TT
    - Gilt für: defensiv | ausgewogen | aggressiv | alle
    - Beobachtung: was ist passiert (mit Journal- und Trade-IDs)
    - Schlussfolgerung: welche Regel oder Anpassung folgt daraus
    - Prüfkriterium: woran man später erkennt, ob sie stimmt
    - Status: Hypothese | bestätigt | verworfen (mit Datum)

Grundsatz: Eine Erkenntnis aus einem einzelnen Trade bleibt Hypothese.
Bestätigt wird sie erst durch mehrere unabhängige Beobachtungen.

(noch keine Einträge)
